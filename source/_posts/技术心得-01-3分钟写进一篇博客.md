# 这篇文章解决什么问题

一句话：你写完 Markdown 后，怎么让它真正出现在博客里。

# 1\. 新建文章文件

在项目根目录执行：

```powershell
cd d:\Github_Storage\myblog\blog-folder
npx hexo new "你的文章标题"
```

执行后会在 `source/_posts/` 里生成一个 `.md` 文件。

# 2\. 填写文章头部（最关键）

打开新文件，确认头部是这个结构：

```yaml
---
title: 你的文章标题
date: 2026-05-08 14:00:00
categories:
  - 技术心得
tags:
  - 关键词1
  - 关键词2
---
```

你现在可用的分组是：

-   文学随笔
-   诗歌归档
-   技术心得

`categories` 写错字或写成其他名字，会导致分组不对。

# 3\. 写正文内容

正文直接写 Markdown 即可，例如：

```markdown
## 背景
我为什么写这篇文章。

## 过程
我做了什么，遇到什么问题，怎么解决。

## 结论
最终结果和可复用经验。
```

# 4\. 本地预览

```bash
npx hexo clean
npx hexo s
```

浏览器打开 `http://localhost:4000` 看效果。

# 5\. 生成与发布

只生成静态文件：

```bash
npx hexo generate
```

直接按你的部署配置发布：

```bash
npx hexo deploy
```

# 常见坑（快速排错）

-   文章没出现：先看文件是否在 `source/_posts/` 下。
-   分类页没显示该分类：确认 `categories` 名字完全一致。
-   页面报错：检查头部 `---` 是否成对出现。
-   PowerShell 报脚本限制：可改用 `cmd /c npx hexo s` 执行。

# 一套最小写作模板

复制下面这段就能开始写：

```yaml
---
title: 标题
date: 2026-05-08 14:00:00
categories:
  - 技术心得
tags:
  - Hexo
---
```

如果你只记一件事：先写对 `categories`，再写正文。
